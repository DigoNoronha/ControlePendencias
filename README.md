# Pauta

Controle de pendências e tarefas por cliente, com prazos, lembretes e entrada por texto livre (Quem / Oque / Quando) com suporte a ditado por voz.

Aplicativo de página única (HTML + CSS + JavaScript), sem backend. Os dados ficam no armazenamento local do navegador. Publicado via GitHub Pages para acesso em HTTPS (necessário para que a permissão de microfone fique memorizada).

## Como usar

- Abra a página publicada (GitHub Pages) no computador ou no celular.
- Para instalar no celular, use "Adicionar à tela inicial" pelo navegador.
